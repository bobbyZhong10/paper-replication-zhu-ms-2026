# Data

The files come from the replication package of Kai Zhu, Qiaoni Shi, Shrabastee Banerjee (2025) Monetizing Platforms: An Empirical Analysis of Supply and Demand Responses to Entry Costs in Two-Sided Markets. Management Science 72(3):2380-2397. https://doi.org/10.1287/mnsc.2023.01390. The package is part of the Supplemental Material at https://pubsonline.informs.org/doi/suppl/10.1287/mnsc.2023.01390.

| File | Used for |
|---|---|
| `supply/giveaways_3participation_supply_selfControl.csv` | Table 2 |
| `supply/book_3participation_supply_selfControl.csv.bz2` | Table 2 |
| `genre/giveaway_genre_proportion_long.csv` | Table 3 |
| `demand/review_vol_yearmon.Rds` | Table 4 |

The files are the same as in the package, except that the book file is compressed with bzip2 to stay under the GitHub file size limit. Variable definitions are in `data-dictionary.xlsx` in the package.
